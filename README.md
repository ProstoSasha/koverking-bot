# Бот студии тафтинга «Ковёркинг» + запись с сайта

Что умеет:
- **Запись в Telegram**: групповой МК, МК-свидание, день рождения / корпоратив в студии, заявка на выездной МК.
  Считает свободные места, держит бронь 6 часов, принимает предоплату по ссылке ЮKassa или номер подарочного сертификата.
- **Подарочные сертификаты**: размер, количество (со скидкой), один на всех или отдельный на каждого, PDF или печатный.
  PDF собирается по шаблону автоматически и уходит клиенту в Telegram и на почту.
- **Сайт (Тильда)**: тот же функционал в окне на сайте (файл `widget.html`). Бот сам запускает вход для сайта на порту 3000.
- Напоминания: об оплате брони, за 24 часа до МК (с фото пути), тем, кто смотрел и не записался, просьба об отзыве после МК.

Всё хранится в Google Таблице.

## Файлы
| Файл | Что внутри |
|---|---|

| `assets/` | картинки, шаблон сертификата, шрифты |

## Настройки (переменные окружения в панели bothost)
| Имя | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `MANAGER_ID` | числовой Telegram ID менеджера (сюда приходят заявки и кнопки «оплата пришла») |
| `SHEET_ID` | ID таблицы (между `/d/` и `/edit` в ссылке) |
| `TIMEZONE` | `Europe/Kaliningrad` |
| `GOOGLE_CREDS_JSON` | всё содержимое файла `credentials.json` |
| `SMTP_PASSWORD` | пароль приложения Google для koverkingtafting@gmail.com (без него письма не отправляются) |
| `PORT` | не обязательно, по умолчанию 3000 |

Файлы `.env` и `credentials.json` на GitHub **не загружать**.

## Таблица
Листы бот создаёт сам: **Записи**, **Сертификаты**, **Групповые**, **Закрытые**, **Интерес**.
- **Групповые** — правки к расписанию: «Занято вручную», «Скрыть» = да, другое число мест, дополнительные даты.
  По умолчанию групповые каждую сб и вс в 11:00 и 17:00, по 6 мест.
- **Закрытые** — когда студия занята: Дата, Дата до, С, До (пустые С/До — весь день).
- **Записи → Статус**: «Ждёт предоплаты» → «Проверяем оплату» → «Оплачено». «Отменено» — освобождает место.
  Статусы меняются кнопками у менеджера, вручную править не обязательно.

## Команды
`/start`, `/menu` — меню; `/cancel` — выйти из диалога; `/list` (только менеджер) — ближайшие записи.

## Ссылки
- Сразу открыть запись в боте: `https://t.me/<ник_бота>?start=book`
